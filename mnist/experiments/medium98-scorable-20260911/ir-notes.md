# Exact scalar program and compressed scoring

This is an implementation of a restricted compiler and scorer for the pinned v4 model, not a new hardware model. The complete program receives the training images, training labels and query images; initializes each ensemble member; trains every batch and epoch; sums query logits in member order; and sends the smallest class attaining the maximum. The program contains no learned constants or test labels. Production initial parameter words must come from the retained seed-only exporter.

Every leaf is `set`, `recv`, `send`, `copy`, `add`, `sub`, `mul`, `div`, `cmp`, or `select`. Bounded loops and named contiguous arrays describe a finite straight-line program. They do not change instruction prices. Multiplication, addition, subtraction and division round separately to FP32. A `select` reads both candidates, including the unused one. Aliased sources are charged separately. `recv` and `send` use the model's free tape interface.

Convolution, dense layers, ReLU, bilinear input augmentation, momentum, coupled weight decay and the approximate-softmax gradient have explicit scalar implementations. Batch normalization, when enabled, also has explicit ordered channel sums and a fixed 16-step Newton square root. The compiler uses no unpriced `conv`, `exp`, `sqrt`, autograd or optimizer instruction. The approximate-softmax formula uses ten literal squarings and a division, rather than claiming equivalence to an exponential implementation.

The seed-only schedule is a program-generation convenience. Its lookup indices are affine expressions in bounded loop variables. They never depend on training values, labels, predictions, or runtime memory. Expansion resolves each lookup into an ordinary fixed scratch address or a `set` immediate. Initial words are embedded as compressed uint32 literals. The only procedural table generator is the pinned local schedule source; production tables additionally pin every epoch's generated array hashes and reject a mismatch. Trigonometry and random generation happen while constructing this fixed input-independent program. Every resulting interpolation coefficient is nevertheless materialized by a charged `set` in the executed program.

Scratch arrays occupy consecutive cells in the fixed half-diamond placement. A single maximum-batch workspace is reused across epochs, inference batches and sequential ensemble members. Raw query inputs remain resident once. Every allocated cell is explicitly initialized, and those writes are charged. The validator proves writes precede reads; it recognizes whole-array initialization exactly and rejects a program if its remaining ordered initialization proof exceeds its work limit. This is a deliberately restricted accepted language, rather than a claim to decide validity of arbitrary programs.

The scorer sums exact per-address read/write multiplicities. Affine accesses use integer convolutions; seed-only nonaffine gathers are streamed from the actual fixed maps and counted. It does not enumerate the enormous dynamic arithmetic trace or accept author-supplied operation counts. Shell aggregation changes only the order of integer cost addition. Address bounds, physical placement, access floors and finite instruction-count limits are checked before reporting a score.

The physical specification remains in its exact native units. At Manhattan distance `h`, one access costs `max(50, 2h)` fJ; a read costs `max(250, 4h)` ticks and a write costs `max(250, 2h)` ticks, with each tick equal to 0.2 ps. Occupied-cell area is one square micrometer per word. Display conversions are `time_ms = ticks / 5 / 1e9`, `energy_mJ = energy_fJ / 1e12`, and `area_mm² = words / 1e6`. Scoring wall time is reported in seconds and includes validation, literal decoding, generated-map verification, histograms and exact cost sums; program construction and output-file writing are separate.

Validation includes fully expanded synthetic complete learners with multiple members, epochs, partial batches, 9×9 inputs and optional batch normalization. Their parameter, momentum, running-statistic, score and prediction bits agree with separately written ordered NumPy references. Every address histogram and physical total agrees with the expanded machine. Additional checks compare BN directly with the independently owned reference, reject invalid reads and bounds, verify 150 Cartesian affine cases, price over a million initialized cells independently, and reproduce the historical complete 1NN score exactly. These tests are numerical/compiler evidence; accuracy on the formal draws and the actual A100 measurements must be established separately for the frozen configuration.
