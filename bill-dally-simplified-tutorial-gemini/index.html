The Simplified Dally Model

In modern computing hardware, arithmetic is virtually free. Moving data is what costs energy and time. In his landmark 2022 CACM viewpoint, Stanford & NVIDIA Chief Scientist Bill Dally proposed pricing algorithms by their physical data movement on a Manhattan grid. Here is an interactive, step-by-step exploration of how the model works.

“Arithmetic has become essentially free. A 64-bit floating-point add takes about 100 fJ, while reading two operands from a local memory and writing back the result takes 10 pJ — 100× more energy than the computation itself.”

— William J. Dally, On the Model of Computation (Communications of the ACM, May 2022)

01 The 2D Memory Arena & Geometric Rules

In the simplified Dally model, a single processor sits at the origin (0, 0). Memory cells are laid out in the 2D upper half-plane (y ≥ 1), concentric ring by ring, spiraling outward.

A memory cell with linear address addr sits on ring k = ⌈√addr⌉ at Manhattan distance |x| + y = k from the processor.

Priced cost = ⌈√i⌉
1. Reads are Priced

Fetching a value from memory cell i costs exactly its Manhattan distance from the processor: |x| + y.

Priced cost = ⌈√i⌉
2. Writes are Priced

Writing a computed result back to cell i incurs the identical Manhattan distance cost for transmitting data across wires.

Free cost = 0
3. Arithmetic is Free

Once operands are latched into local processor registers, computing (add, sub, mul) costs zero energy units.

📐
The Routing Invariant: Transfers always travel horizontally first along the baseline, then vertically up to the target cell ((0,0) → (x, 0) → (x, y)). Because this L-shaped wire has length |x| + y, the drawn path length always exactly equals the billed energy cost!

05 Why This Changes Algorithm Design

In classical RAM models (such as $O(1)$ uniform memory access), matrix multiplication $C = A \times B$ is analyzed purely by counting arithmetic operations ($2N^3$ FLOPs). Under the Dally model, however, reading un-cached matrices from memory distance $O(N)$ dominates everything.

Spatial Locality

Data residing in ring 1 costs 1 unit to access; data in ring 10 costs 10 units. Packing frequently used variables close to the processor yields exponential energy savings.

Scratchpad Tiling

Copying a distant value once to a nearby scratchpad register allows multiple cheap re-reads, drastically outperforming naive memory streaming.

Systolic & TPU Arrays

Passing operands directly from one neighbor ALU to the next (distance = 1) is why modern AI accelerators (TPUs, Tensor Cores) achieve orders of magnitude better energy efficiency.
