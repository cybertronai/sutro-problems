## Method

This improves the current 64,074 record by **227 (0.3543%)** and the earlier
64,431 published record by **584 (0.9064%)**. These are abstract Dally v0
operand/output read costs, not measured runtime or joules.

The classical 4,096 scalar products use asymmetric column panels of widths
5 and 11, with row groups `3/3/3/3/4` and `5/5/6`, respectively. This is a
separate geometry seed scoring 64,327, not a postprocess of the 64,074 artifact.
Alternating input-replica captures and physical address allocation gives:

| Stage | Cost | Accepted captures |
|---|---:|---:|
| Geometry seed | 64,327 | - |
| Capture 1 | 64,061 | 158 |
| Allocate 1 | 64,008 | - |
| Capture 2 | 63,914 | 89 |
| Allocate 2 | 63,896 | - |
| Capture 3 | 63,850 | 45 |
| Allocate 3 | **63,847** | - |

The 292 accepted captures preserve temporary input replicas at cheap addresses.
Each insertion is evaluated against the current batch, including eviction of
the destination's previous value. Reads select the cheapest surviving equivalent
source. Allocation compares fresh weighted-DP and incumbent starts with four
pair-refinement rounds, ties enabled, and cycle seeds 0, 17, and 34. All accepted
stages are non-worsening; dead-copy cleanup removed no copies.

This is an allocation/capture heuristic, **not reinforcement learning**. The
search stopped at its time budget; the final allocation has no completed
zero-gain capture pass (`stable: false`, `timed_out: true`). Neither local nor
global optimality is claimed.

All 512 inputs and 256 outputs are checked exactly. Each operand and output
read pays `ceil(sqrt(address))`; arithmetic and writes are free, and reads
precede writes.

## Verification and Scope

```sh
python3 -S matmul/submissions/best_63847.py
python3 -S -m unittest matmul.test_record_63847 -v
```

also works by absolute path from another directory. It checks the byte hash,
unchanged official symbolic scorer, independent exact noncommutative-polynomial
proof, operation counts, and full read-cost breakdown. It uses only repository
code and the frozen IR, with no external workspace, OR-Tools, or Torch dependency.

search implementation, or byte-identical construction replay is included.
