Naive Matmul, Priced

The baseline triple loop, executed one memory access per clock under the simplified Dally model: an access to address a costs ⌈√a⌉; writes and arithmetic are free.

Layout

The cell at linear index a sits at Manhattan distance ⌈√a⌉ from the core, so ring k holds 2k−1 cells. The arrays are placed contiguously, which leaves the output furthest from the core.

Locality across algorithms

Each program is generated and simulated in-page, then plotted per access. Address is the linear memory index touched at that clock, so loop structure shows up directly as bands and sweeps; access cost is what the model charges for it, ⌈√a⌉.

Where the energy goes

Two thirds of the 4×4 bill is scratch traffic. Every one of the 48 accumulate steps reads C[i,j] at distance 6–7 and tmp at distance 7, so tmp alone (336) costs more than every access to A (200). The same shape holds at every size: tmp is 16 of the 84 units at 2×2 and 108 of 429 at 3×3. The 800-cost 4×4 record restructures the loop as outer products, keeping the accumulator and the broadcast operand in the cheapest addresses.
