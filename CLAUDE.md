# Sutro problems

## Responses

Whenever a response involves an artifact or a GitHub Pages link, put it at the
**very end of the message**, after all prose — never buried mid-explanation.

This covers:

- Artifacts you produced or updated (files, reports, plots, generated IRs).
- GitHub Pages URLs under `https://cybertronai.github.io/sutro-problems/`, e.g.
  the [benchmark report](https://cybertronai.github.io/sutro-problems/docs/),
  the [spatial-model analysis](https://cybertronai.github.io/sutro-problems/docs/spatial-model-analysis.html),
  and the [sparse-parity page](https://cybertronai.github.io/sutro-problems/sparse-parity/).

Pages is served by Jekyll from the root of `main`, so a page is only live once
its commit is pushed. If it is not pushed yet, say so next to the link rather
than implying the URL already resolves.
